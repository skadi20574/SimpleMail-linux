# 安装与使用说明

适用于 Ubuntu 22.04 LTS / 24.04 LTS / 26.04 LTS（其他 glibc ≥ 2.31 的发行版基本也可以）。

本项目提供三种分发形态，按「省事程度」排序：

| 形态 | 适合场景 | 依赖处理 | 沙箱 |
| --- | --- | --- | --- |
| **`.deb`**（推荐） | 本机长期使用 | 自动装依赖，进「应用程序」菜单 | ✅ 真正开启 |
| **`.tar.gz`**（便携） | 拷到别的机器直接用，不装任何东西 | 无额外依赖，不需要 FUSE | ⚠️ 自动关闭 |
| **`.AppImage`** | 单文件分发 | 需要系统有 `libfuse2`（见下） | ⚠️ 自动关闭 |

> 沙箱那一列的解释：Electron 的渲染进程沙箱依赖 `chrome-sandbox` 带 setuid root 位。
> `.deb` 安装时安装后脚本会设好这个权限，沙箱真正开启；AppImage / tar.gz 无法 setuid，
> 而 Ubuntu 23.10 起又用 AppArmor 禁掉了非特权用户命名空间，两者都不可用，
> 所以这两种形态的启动器会自动补上 `--no-sandbox`。程序里已带一层 shell 启动器
> 自动判断，**你不需要手动加任何参数**。详见 `src/main/index.ts` 顶部注释。

## 一、`.deb` 安装包（推荐）

```bash
# 方式 1：双击 release/SimpleMail_1.0.0_amd64.deb，在软件中心里点「安装」

# 方式 2：命令行
sudo apt install ./SimpleMail_1.0.0_amd64.deb
# 用 apt 而不是 dpkg，是为了让依赖被自动装上
```

装完后：

- 程序在 `/opt/SimpleMail/`
- 应用菜单里会出现 **SimpleMail**（也可以终端执行 `simplemail` 启动）
- 需要卸载时：`sudo apt remove simplemail`

### 如果 `apt install` 报依赖缺失

换用 `dpkg` 再补齐依赖：

```bash
sudo dpkg -i SimpleMail_1.0.0_amd64.deb
sudo apt-get -f install
```

### 各版本所需依赖

包里的 `Depends` 字段已经写成 Ubuntu 22.04 / 24.04 / 26.04 都能解析的旧包名
（24.04 起的 `t64` 过渡包会把旧名字作为 `Provides` 提供）：

```
libgtk-3-0, libnotify4, libnss3, libxss1, libxtst6, xdg-utils,
libatspi2.0-0, libsecret-1-0, libgbm1, libasound2, libuuid1
```

## 二、`.tar.gz` 便携版（拷过去就能用）

最省事、最不挑环境的一种，不需要 root、不需要 FUSE、不需要装任何东西：

```bash
tar -xzf simplemail-1.0.0.tar.gz
cd simplemail-1.0.0        # 实际解出的目录名以 tar 输出为准
./simplemail
```

想做个桌面快捷方式的话，自己写一个即可（把路径换成实际解压位置）：

```bash
cat > ~/.local/share/applications/simplemail.desktop <<EOF
[Desktop Entry]
Type=Application
Name=SimpleMail
Comment=本地优先的邮件客户端
Exec=$HOME/apps/simplemail/simplemail %U
Icon=$HOME/apps/simplemail/resources/app.asar.unpacked/../icon.png
Terminal=false
Categories=Network;Email;
EOF
```

> 分发到别的 Ubuntu 机器时，直接把解压好的目录拷过去即可。程序本身不依赖
> Node.js、Rust 工具链或任何开发环境。

## 三、`.AppImage`

```bash
chmod +x SimpleMail-1.0.0-x86_64.AppImage
./SimpleMail-1.0.0-x86_64.AppImage
```

### 提示 `libfuse2` 缺失怎么办

Ubuntu 22.04 之后**默认不再安装 `libfuse2`**，AppImage 会报：

```
dlopen(): error loading libfuse.so.2

AppImages require FUSE to run.
```

这**不是安装包坏了**，三种解决办法任选：

```bash
# 办法 1：装上 libfuse2（一次即可）
sudo apt install libfuse2        # Ubuntu 22.04
sudo apt install libfuse2t64     # Ubuntu 24.04 / 26.04

# 办法 2：不装 FUSE，让 AppImage 自己解压运行
./SimpleMail-1.0.0-x86_64.AppImage --appimage-extract-and-run

# 办法 3：直接用上面的 tar.gz 便携版，或 .deb
```

## 四、首次使用

### 1. 添加邮箱账户

点左下角「**＋ 添加邮箱账户**」，从预设里选你的邮箱类型，填地址和密码。

| 邮箱 | 需要做什么 |
| --- | --- |
| **QQ 邮箱** | 网页版 → 设置 → 账户 → 开启 **IMAP/SMTP 服务**（用 POP3 则开启 **POP3/SMTP 服务**）→ 生成 **16 位授权码**；本程序密码处**填授权码，不是 QQ 密码** |
| **163 / 126** | 网页版 → 设置 → POP3/SMTP/IMAP → 开启对应服务 → 设置**客户端授权码** |
| **腾讯企业邮** | 用邮箱地址 + 客户端专用密码 |
| **Gmail** | 开启两步验证 → 生成「应用专用密码」 |
| **Outlook** | 若账户强制 OAuth 则无法用密码登录（本项目不支持 OAuth） |

#### 收件协议选 IMAP 还是 POP3

程序里每个账户可以单独选，预设已经把两种协议的服务器地址都填好了：

| | IMAP（推荐） | POP3 |
| --- | --- | --- |
| 文件夹 | 服务器上的文件夹全部同步过来 | **只有收件箱**，其余是本地文件夹 |
| 已读 / 星标 | 与服务器同步，手机电脑一致 | **没有**（协议不支持） |
| 多发件箱同步 | 是 | 否，已发送只存本机 |
| 增量方式 | UID + UIDVALIDITY | UIDL |
| 默认端口 | 993（SSL） | 995（SSL）；110 需 STLS 升级 |
| 适合 | 绝大多数情况 | 只在一台电脑上收信的老邮箱 |

选 POP3 后会出现一个选项：**下载成功后从服务器删除这些邮件**。

> 默认**不勾选**：邮件下载到本机后服务器上仍保留，可以再用手机或别的客户端收。
> 勾选后本机就成了唯一副本，**换电脑前请先做一次「导出存档」备份**。
> 删除只在邮件成功写入本地数据库之后才执行，同步中途取消不会删。

填完点「**测试连接**」，IMAP 与 SMTP 都通过再保存。保存后会自动开始第一次同步。

### 2. 关于第一次同步

同步分两段，节奏是「列表先出来，正文慢慢补齐」：

1. **抓信封**：只取 `Message-ID` / 主题 / 发件人 / 日期 / 标志位，很快，列表立刻可用；
2. **补正文**：后台把还没下载的邮件整封拉下来，解析后写入本地库，附件落到磁盘。

首次同步默认只抓每个文件夹最近 500 封（可在「设置 → 常规」里调整）。之后每次同步
都按 IMAP UID 增量抓取，不会重复下载。

**同步下来的邮件永久保存在本机，程序不会自动清理。**

### 3. 导入以前的 Foxmail 存档

点工具栏「**导入存档**」→「浏览…」，可以选：

- 一个 `.fox` 文件（Foxmail 7.2 的「邮件存档」产物）
- 一个 Foxmail 数据目录（含 `mail/` 或 `Storage/` + `FMStorage.list`）
- 一个 `.zip`（里面是上面任意一种）
- 一个 `.box` / `.mbox` 文件，或装着 `.eml` 的目录

程序会**自动识别格式**，不需要你选版本。识别结果会显示出来，确认后点「开始导入」。

建议给每年的存档填一个批次标签（如 `Foxmail存档2023`），之后在邮件预览里能看到
「存档：Foxmail存档2023」，设置里也有导入记录。**同一年份重复导入会自动跳过重复邮件。**

### 4. 导出存档

工具栏「**导出存档**」。可以同时勾选多种格式：

| 格式 | 用途 |
| --- | --- |
| `.fox` | SimpleMail 自有容器，**本程序可 100% 无损读回**（自带清单，不依赖任何猜测） |
| `.box + .ind` | 老版 Foxmail 目录结构。如果这批邮件当初就是从 Foxmail 导入的，会**沿用当时自标定出的索引布局**写回 |
| `.eml` | 每封一个文件，Foxmail 可直接导入，通用性最好 |
| `.mbox` | Thunderbird / mutt / Outlook 都能读 |

> 提醒：`.fox` 是 Foxmail 的闭源私有格式，本项目导出的 `.box/.ind` 不保证被 Foxmail
> 原样识别。要放回 Foxmail 用，**优先用 `.eml` 或 `.mbox`**（导出时会一并产出）。

### 5. 键盘操作与批量处理

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 上下浏览邮件 |
| `Ctrl` + 单击 | 逐封加选 / 取消 |
| `Shift` + 单击、`Shift` + `↑↓` | 范围选择 |
| `Ctrl` + `A` | 全选 |
| **`Delete`** | **移到垃圾箱** |
| **`Shift` + `Delete`** | **永久删除**（本机正文与附件文件一并清掉） |
| `M` / `S` | 批量标已读 / 加星标 |
| `Ctrl` + `N` / `R` / `L` | 写邮件 / 回复 / 转发 |
| `Ctrl` + `F` | 跳到搜索框 |
| `F5` | 同步 |
| `Esc` | 退出输入框 / 清空搜索 / 收回多选 |

鼠标操作：行首悬停或选中时出现复选框，可以直接勾选；表头复选框是全选。

**关于 `Shift+Delete`**：确认后本机数据库记录和磁盘上的附件文件都会被删除，无法从本机恢复。
IMAP 账户会同时在服务器上把这封移到垃圾箱（避免下次同步又回来），所以服务器上仍可从垃圾箱找回；
POP3 与本地存档账户没有服务器副本，就是纯本机删除。

在**垃圾箱**里按 `Delete` 等同于永久删除。

### 6. 搜索

顶部搜索框对**全部账户的全部邮件**做全文检索，覆盖主题、正文、发件人、收件人。

搜索框左边的下拉可以把范围限定到 **全部字段 / 发件人 / 收件人 / 主题 / 正文**。
比如选「发件人」再输入关键词，就只在发件人字段里找，不会把正文里提到这个词的邮件也捞出来。

**结果默认按匹配度排序**（词频高、内容短的排前面）。列表头会出现「相关度」按钮，
点「时间 / 主题 / 发件人」可以切回常规排序，再点「相关度」切回来。

中文可以搜 1~2 个字的短词（比如「发票」「合同」），这得益于把汉字逐字建索引、
查询时转成短语匹配的做法（`cjk:"发 票"`）。

### 7. 文件夹管理（像文件管理器一样）

左侧文件夹**右键**会弹出菜单：新建子文件夹 / 新建同级文件夹 / 重命名 / 删除文件夹 / 立即同步。
账户名右边的 **＋** 按钮可以直接在账户根下新建。

**拖拽归类**：在邮件列表里把邮件拖到左侧任意文件夹上松手就移动过去了（目标文件夹会高亮）。
拖的是**已选中的那批**——如果拖的那封在多选范围里，整批一起走；只想移一封就先按 `Esc` 取消选择。

**删文件夹时会问里面的邮件怎么办**：

- **移到垃圾箱**（推荐）：邮件还在本机垃圾箱里，能找回；
- **连同邮件永久删除**：本机记录和磁盘附件一起清掉，不可恢复。

**收件箱不能删也不能改名** —— 它是 IMAP 同步的锚点。

IMAP 账户的文件夹操作会**同步到服务器**（新建/改名/删除都会反映到手机端）。
本地存档账户和 POP3 账户只有本地文件夹，这是协议本身的限制。

### 8. 主题切换

工具栏上有一个切换按钮，图标分别是：

| 图标 | 模式 | 说明 |
| --- | --- | --- |
| 小太阳 | 浅色 | — |
| 月亮 | 深色 | 夜间看着不刺眼 |
| 半明半暗的圆 | 跟随系统 | 跟着桌面环境的深浅色自动切换 |

点一下切换一个模式。也可以在「设置 → 常规 → 界面主题」里直接选。

### 9. 自定义快捷键

「设置 → 快捷键」里可以改任何一个按键：

1. 找到要改的动作，点右侧的「修改」；
2. 直接按下你想要的组合键（只按修饰键不算，会被忽略）；
3. 想取消就按 `Esc`。

如果同一个按键被分给了两个动作，那一行会标红 —— 重复时只有靠前的动作会生效。
想恢复出厂设置，点「全部重置为默认」即可。

单键操作（`M`、`Delete` 之类）不会在输入框里误触发；标了「输入框内也可用」的
组合键（写邮件、回复、搜索）在输入框里也生效。

### 10. 右键菜单、双击开窗与未读标记

**未读邮件最左边是绿色圆点，已读邮件是灰色小对勾** —— 两种状态都有标记，一眼就能区分。
已加星标的是橙色五角星（和圆点各占一格，可以同时出现）。鼠标划过时再出现复选框，
三个格子都固定占位，所以行内文字不会左右跳动。

**打开邮件是否自动标记已读**：「设置 → 常规 → 打开邮件后自动标记为已读」，默认开着。
关掉之后用右键菜单的「标记为已读 / 标记为未读」，或者按 `M` 键手动切换 ——
两个方向都在菜单里，多选时状态混杂也能用。

**右键单击邮件**会弹出系统原生菜单：

| 菜单项 | 说明 |
| --- | --- |
| 在新窗口打开 | 把邮件放到独立窗口读，方便对照着看 |
| 标记为已读 / 未读 | 单选或多选都行，蓝点随之消失或出现 |
| 加星标 / 取消星标 | — |
| 回复 / 回复全部 / 转发 | 多选时不可用 |
| 移动到 ▸ | 罗列当前账户的文件夹 |
| 移到垃圾箱 / 永久删除 | 和 `Delete` / `Shift+Delete` 一样 |

**双击邮件**会在新窗口里打开它。同一封重复双击只会聚焦已有窗口，不会开出一堆。
独立窗口里按 `Esc` 可以关闭。

### 11. 自动归类 / 自动删除规则

工具栏「**规则**」按钮。规则在邮件**收到的那一刻自动执行** ——
无论邮件是同步下来的还是从 Foxmail 存档导入的。

举例：

| 想要的效果 | 条件 | 动作 |
| --- | --- | --- |
| 把某个客户的邮件自动归档 | 发件人地址 包含 `customer.com` | 移动到「客户」 |
| 促销邮件直接进垃圾箱 | 主题 包含「促销」或「限时」 | 移到垃圾箱 |
| 订阅邮件不占未读计数 | 主题 开头是 `[订阅]` | 标记为已读 |
| 按邮件列表自动分流 | 指定邮件头 包含 `List-Id: dev.lists` | 移动到「技术」 |

**「指定邮件头」**这一项可以匹配任意自定义字段，写成 `头部名: 内容` 的形式，
比如 `X-Spam-Flag: YES`。

编辑器里的「**试运行（不改数据）**」会拿现有邮件跑一遍条件，告诉你多少封会命中、
并列出样例。**配「永久删除」这类危险规则前请务必先试运行一次** ——
规则是无人值守执行的，不会弹确认框。

「对现有邮件套用一遍」会把新建的规则应用到老邮件上；已经被规则处理过的邮件不会重复处理。

### 12. 邮件阅读

- 正文里的**远程图片默认被阻止**（防止「是否已读」的跟踪像素），预览上方有按钮可临时放行；
- 内联图片（`cid:`）通过应用内部的 `smattach://` 协议加载，可以正常显示；
- HTML 正文在 `sandbox="allow-same-origin"` 的 iframe 中渲染，**脚本被完全禁止**；
- 点「查看原始头」可以看到邮件原始头部。

## 五、数据在哪里

| 内容 | 位置 |
| --- | --- |
| 数据库（邮件正文、头部、附件元数据） | `~/.config/SimpleMail/simplemail.db` |
| 附件 | `~/.config/SimpleMail/attachments/<账户 id>/<邮件 id>/` |

### 备份建议

要完整备份，**拷贝整个 `~/.config/SimpleMail/` 目录**即可（数据库 + 附件 + 设置）。
数据库使用 WAL 模式，建议在程序关闭后再拷。

## 六、卸载

### 在程序里卸载

「**设置 → 关于 → 卸载**」会检测当前的安装方式并给出对应操作：

- **`.deb` 安装的**：点「卸载 SimpleMail」，弹出系统授权对话框，确认后执行
  `apt-get remove simplemail`，程序随即退出。
- **AppImage / 便携版**：直接显示文件（目录）路径和对应的删除命令，
  退出程序后自己删掉即可。

**卸载不会删除你的邮件数据**。要一并清理，用同一个页面里的「清除本地数据」——
它会要求你手动输入 `DELETE` 确认，然后删除数据库、附件目录与导出目录并重启到一个空库。
想留个底的话，先做一次「导出存档」。

### 命令行卸载

```bash
# deb 安装的
sudo apt remove simplemail

# 便携版：直接删掉解压出来的目录

# 数据（卸载不会删，需要手动清）
rm -rf ~/.config/SimpleMail
```

## 七、出问题了怎么办

| 现象 | 处理 |
| --- | --- |
| 添加账户时连接失败 | 确认密码填的是**授权码**而不是登录密码；确认邮箱网页版已开启 IMAP/SMTP 服务 |
| QQ 邮箱提示 `LOGIN fail` | 同上，QQ 必须用授权码；另外注意授权码是 **16 位**的 |
| 界面能开但同步很慢 | 国内网络对部分邮件服务器较慢，属正常；可在「设置 → 常规」调小单次同步数量 |
| POP3 账户看不到「垃圾邮件 / 归档」 | 正常，POP3 没有服务器文件夹概念，只有收件箱 + 三个本地文件夹 |
| 用 POP3 收过的信，手机上收不到了 | 说明该账户勾选了「下载成功后从服务器删除」。可在账户设置里取消勾选；已经被删的无法找回 |
| POP3 同步提示「该服务器不支持 UIDL」 | 程序会退化为全量下载并按 Message-ID 去重，能正常收信，只是每次同步会多花一点时间 |
| 从老版本升级后邮件会不会丢 | 不会。程序会自动把数据库逐版本迁到最新（补 POP3 字段、加规则表、重建全文索引），自检里有专门的迁移测试覆盖 |
| 导入时提示「文件过大」 | 1.1.3 起 GB 级 `.box` 走流式导入，不再受内存限制。若仍报错，说明超过了 64GB 的安全上限 |
